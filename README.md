# Allvision Studio: AI-сервис цифровых подарков и видеоредактор

Пользователь выбирает готовый сценарий, загружает фотографии и получает изображение или видео. Результат можно доработать в редакторе: собрать клипы, добавить текст, музыку и озвучку, затем экспортировать ролик. Для индивидуальных заказов есть бриф и кабинет администратора.

## Что сделано

- Каталог услуг и шаблонов видеопоздравлений.
- Пайплайны генерации из настраиваемых AI-блоков, формы ввода и цены услуг.
- Видеоредактор с дорожками, слоями, переходами, обрезкой, звуком и отменой действий.
- Фоновая генерация и рендер через очередь; прогресс приходит в браузер по SSE.
- Личный кабинет, баланс токенов, платежи, промокоды и возврат средств при ошибках.
- Заказные работы, поддержка и админка для управления каталогом и заказами.
- Mock-режим для локальной разработки без ключей платных AI-сервисов.

## Как устроен проект

Монорепозиторий на npm workspaces:

| Папка | Назначение |
| --- | --- |
| `apps/web` | Next.js, React, TypeScript, RTK Query; витрина, кабинет и редактор |
| `apps/api` | Express, REST API, авторизация, загрузки, платежи и SSE |
| `apps/worker` | BullMQ, AI-провайдеры и рендер видео через ffmpeg |
| `packages/database` | Prisma, PostgreSQL, миграции и демо-данные |
| `packages/shared` | Общие контракты, Zod-схемы, каталог моделей, цены и таймлайн |

API проверяет запрос и ставит задачу в Redis. Worker выполняет шаги, сохраняет результат и обновляет статус в PostgreSQL. Браузер получает прогресс через SSE. Общие правила расчёта цен и структура таймлайна находятся в `shared`, чтобы клиент и сервер использовали одинаковую логику.

Провайдеры вынесены за общий интерфейс. В коде есть интеграции с fal и PiAPI, а локальные сценарии используют MockAIProvider. Состав работающих моделей зависит от выбранного провайдера и настроек.

## Локальный запуск без платных ключей

Нужны Node.js 24, npm, Docker с Compose, а также `ffmpeg` и `ffprobe` в PATH. Видео в mock-режиме тоже требует ffmpeg.

```bash
git clone https://github.com/kvantoniY/allvision-studio.git
cd allvision-studio
cp .env.example .env
docker compose -f docker/docker-compose.yml up -d --wait
npm ci
npx prisma generate --schema packages/database/prisma/schema.prisma
npx prisma migrate deploy --schema packages/database/prisma/schema.prisma
npm run build -w @allvision/database
npm run build -w @allvision/shared
npm run db:seed:dev
npm run demo:download
npm run dev
```

Команда `db:seed:dev` очищает данные в указанной базе. Используйте её только с отдельной локальной базой из Compose. Настройки по умолчанию: PostgreSQL на порту 5433, Redis на 6380, AI и платежи в режиме `mock`.

Сайт: http://localhost:3000. API: http://localhost:4000/api/health. Готовность базы и Redis: http://localhost:4000/api/ready.

В Windows PowerShell используйте `Copy-Item` вместо `cp`. Если PowerShell блокирует `npm.ps1`, запускайте `npm.cmd` вместо `npm`.

## Что проверить

1. Откройте каталог `/services` и страницу услуги.
2. Войдите с почтой `demo@local.ru` и паролем `user123`.
3. Запустите генерацию на mock-провайдере. Должны меняться статус и прогресс, а после завершения появиться файл.
4. В `/editor` соберите короткий ролик из фотографий, добавьте текст и экспортируйте видео.
5. В админке посмотрите конструктор услуги: шаги, форму ввода и цену.

Mock-провайдер выдаёт демонстрационные файлы. Он позволяет проверить приложение и очередь, но не качество AI-модели. Для настоящей генерации нужны ключи и оплаченный баланс провайдера.
